# Doom Double Boulder Practice

Doom Double Boulder Practice is a fan-made browser simulator for practicing the double boulder encounter in Old School RuneScape. It provides a practice arena with a player, boss, inventory, prayer controls, projectiles, audio cues, and encounter timing. It is not an official game client, training tool, or Jagex product.

## How to use

Open the live site in a modern browser, adjust the inventory and camera during the ready stage, then press Start. Use the displayed keybinds to switch attack style, inventory, and prayer tabs. Move around the arena, select protective prayers, and observe the boss’s attacks and boulder patterns. Audio controls change or mute the included cues. Restart begins a fresh attempt. Controls are for practice. Browser audio may require interaction before playback.
